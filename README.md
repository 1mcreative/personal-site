# personal-site

Personal website under [1mcreative](https://github.com/1mcreative) for:

- Resume
- Instagram and hobbies
- Interview experience
- Interview question set hosting

## Pages

| Path | Purpose |
| --- | --- |
| `index.html` | Home |
| `resume/` | Resume |
| `life/` | Instagram and hobbies |
| `interviews/` | Interview experience |
| `questions/` | Interview question sets |

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080
