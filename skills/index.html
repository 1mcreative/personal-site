Claude Skills

A Claude Skill is one file, SKILL.md, that teaches Claude how to do a specific job well — a workflow, a set of rules, a review checklist. This whole site is built and run with Claude Code, and these are the actual skills behind it, not generic advice. Building something of your own? Take one.

How to install a skill

Every skill below is a zipped SKILL.md folder. Download it, unzip it, then hand it to Claude one of these ways.

Claude Code (CLI)

  1. Unzip the download — you get a folder named after the skill, with SKILL.md inside.
  2. Drop that folder into your skills directory:
# this project only
mkdir -p .claude/skills
mv resume-tailor .claude/skills/

# every project you work on
mkdir -p ~/.claude/skills
mv resume-tailor ~/.claude/skills/

Restart Claude Code (or start a new session). It picks the skill up automatically when what you ask for matches it, or you can invoke it directly by name.

Claude.ai, desktop & mobile apps

  1. Unzip the download — you only need the SKILL.md file inside.
  2. Open Settings → Capabilities → Skills (Pro, Max, Team, and Enterprise plans).
  3. Upload SKILL.md and turn the skill on.

Exact menu names shift between app versions — if "Skills" isn't under Capabilities, check Settings for it directly.

Your own agent (Developer Platform / Agent SDK)

  1. Point your agent's skills directory at the unzipped folder, the same way you'd load any other skill in your setup.
  2. Claude picks it up the next time that agent starts.
